Zero Tolerance for "Close Enough"

Three independent layers prevent hallucination. Every recommendation is traceable.
Engine Guard Layer 1
Checks all required parameters are resolved before generating a verdict. Missing airflow? Blocks recommendation, asks for clarification.
Python Guard Layer 2
Keyword filter in retriever ensures resolved parameters are not re-asked. Prevents "Context Amnesia" across conversation turns.
LLM Guard Layer 3
Prompt injection marks known values as resolved. LLM receives explicit instruction: "KNOWN: width=1200mm. DO NOT ask again."

Why This Matters

M+H filters protect BSL-4 containment laboratories. Ebola. Marburg. No cure. Wrong filter specification = aerosol transmission risk.

A "close enough" answer from a generic AI is not acceptable. The system must be deterministic and verifiable.

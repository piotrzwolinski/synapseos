The Core Question

Who Owns the Reasoning?

?

LLM-Only Approach

Reasoning lives in the model
  • Rules are implicit — learned from training data
  • Cannot inspect why a decision was made
  • Model update = your outputs change overnight
  • No way to fix a single wrong rule
  • Vendor controls the logic, not you
  • Compliance: "the AI decided" is not an answer
You rent the reasoning. You don't control it.
◆

Knowledge Graph

Reasoning lives in your data
  • Every rule is an explicit, editable data node
  • Full traceability: this node triggered this decision
  • You change a rule, the output changes — predictably
  • One wrong constraint? Fix that one node
  • The graph is your IP, in your infrastructure
  • Compliance: every answer maps to a source
The reasoning logic is a data asset you control.

An LLM is a narrator. The Knowledge Graph is the source of truth. When both work together, you get intelligence you can trust, audit, and scale.

Safety & Compliance

Zero Tolerance for "Close Enough"

Three independent layers prevent hallucination. Every recommendation is traceable.
Engine Guard Layer 1
Checks all required parameters are resolved before generating a verdict. Missing airflow? Blocks recommendation, asks for clarification.
Retriever Guard Layer 2
Programmatic filter ensures resolved parameters are not re-asked. Prevents "Context Amnesia" across conversation turns.
LLM Guard Layer 3
Prompt injection marks known values as resolved. LLM receives explicit instruction: "KNOWN: width=1200mm. DO NOT ask again."

Why This Matters

M+H filters protect BSL-4 containment laboratories. Ebola. Marburg. No cure. Wrong filter specification = aerosol transmission risk.

A "close enough" answer from a generic AI is not acceptable. The system must be deterministic and verifiable.

EU AI Act: High-risk systems require full traceability.

Full Audit Trail

Every recommendation links back to:

  • Which graph nodes were traversed
  • Which rules triggered or vetoed
  • Which constraints were checked
  • Why alternatives were offered

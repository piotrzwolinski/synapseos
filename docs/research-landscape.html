02 Knowledge Augmentation Papers
CogMG: Collaborative Augmentation Between LLM and Knowledge Graph
ACL 2024 · Zhou, Chen, Liu, Zhao
LLM queries KG → gap detected → LLM decomposes missing triples → completes KG → answers. ReAct agent framework on Wikidata. Fine-tuned open-source LLM.
Gap Detection Triple Decomposition ReAct Agent No HITL No Provenance No Trust Levels
KARMA: Multi-Agent LLMs for Automated KG Enrichment
NeurIPS 2025 · Lu et al. · Code
9 collaborative agents for KG enrichment. Schema alignment + conflict resolution via LLM debate. 38k new entities from 1200 PubMed articles, 83% correctness.
Multi-Agent Schema Alignment Conflict Resolution Batch Only No Real-Time
ClaimVer: Explainable Claim-Level Verification via Knowledge Graphs
EMNLP 2024
Decomposes LLM response into atomic claims. Maps each to KG. Verifies. Generates explanations. This IS our Inference Extractor pattern — classifies GRAPH_FACT vs LLM_INFERENCE.
Claim Decomposition KG Verification Explainability No Enrichment
KG Validation by Integrating LLMs and Human-in-the-Loop
2025 · ScienceDirect
9 validation strategies tested: fully automated → hybrid. Hybrid (LLM + expert) = best F1 (+5%) with minimal human effort. Scientifically validates our architecture choice.
HITL Validation Strategy Comparison Hybrid Optimal
KONDA: LLM-based Semantic Annotation with Human-in-the-Loop
2025
LLM proposes triples → user sees proposal in UI → approve/reject/edit → graph write. Closest to our review UI workflow. Web interface for non-experts.
HITL UI Approve/Reject No Provenance
GoG: Generate-on-Graph for Incomplete KG Question Answering
EMNLP 2024 · Code
Think → Search → Generate. When KG is incomplete, LLM generates missing triples using internal knowledge and verifies them against explored subgraph.
Gap Detection Triple Generation No Persistence No HITL
GraphJudger: Can LLMs be Good Graph Judger for KG Construction?
2024
LLM generates relations → fine-tuned expert LLM judges correctness → filters before graph write. LLM-as-judge alternative to human expert.

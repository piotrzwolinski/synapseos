Infrastruktur — POC vs. Produktion
⚠

Aktueller Stand (POC)

  • Öffentlicher Ingress (kein VNet)
  • Secrets als Terraform-Variablen
  • Keine Netzwerkisolierung
  • Kein Key Vault
  • Kein Monitoring / Alerting
  • Keine CI/CD Pipeline
▶

Produktionsanforderungen

  • VNet + Private Endpoints
  • Azure Key Vault für Secrets
  • RBAC mit granularen Rollen
  • CI/CD Pipeline (Azure DevOps)
  • Monitoring & Alerting (App Insights)
  • WAF / API Gateway
  • Security-Review & Architektur-Abstimmung
Production-Ready MVP — Was dazugehört
⚠

Security

  • Threat Modeling (STRIDE)
  • Penetration Testing
  • Dependency Scanning (CVE)
  • Secret Rotation Policy
  • Security Incident Response Plan
☁

Netzwerk & Isolation

  • VNet mit Subnet-Segmentierung
  • Private Endpoints (DB, Storage)
  • WAF / API Gateway
  • DDoS Protection
  • TLS Everywhere + Cert Management
♟

Identity & Access

  • RBAC mit Least Privilege
  • Managed Identities (keine Keys)
  • Azure Key Vault für Secrets
  • Conditional Access Policies
  • Audit Logging (Entra ID)
↻

CI/CD & Release

  • Azure DevOps Pipelines
  • Staging / Production Environments
  • Automated Testing (Unit, Integration)
  • Image Scanning vor Deploy
  • Rollback-Strategie
◉

Observability

  • Application Insights (APM)
  • Structured Logging
  • Alerting & On-Call Rotation
  • Health Checks & Liveness Probes
  • SLA / SLO Definition
☑

Compliance & Governance

  • DSGVO / Data Residency (EU)
  • Azure Policy & Guardrails
  • Backup & Disaster Recovery
  • Dokumentation & Runbooks
  • Verantwortlichkeiten (RACI)
Keiner dieser Punkte war Teil des POC-Scopes. Für einen produktiven Betrieb müssen diese Bereiche gemeinsam mit MH IT definiert und umgesetzt werden.

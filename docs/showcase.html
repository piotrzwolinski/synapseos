4-Layer Architecture
Each layer builds on the one below. Layer 1 = data, Layer 2 = physics, Layer 3 = strategy, Layer 4 = live state. Adding domain rules = graph mutation, not code.
L4

Session State

Digital Twin

Per-conversation project subgraph. Resolved params, selected products, assembly groups, conversation turns. Persists across turns — this is why the system has no context amnesia. Parameters sync across assembly siblings via assembly_group_id.

Session ActiveProject TagUnit ConversationTurn
Dynamic per session · 15+ tracked params · cross-turn persistence
L3

Playbook

Strategy

Decision trees, logic gates (FIRED/PASSED/VALIDATION_REQUIRED), parameter priority, capacity rules (airflow → module selection), variable features with auto-resolve defaults, and clarification sequencing. This is what makes it a consultant, not a lookup table.

LogicGate Parameter VariableFeature CapacityRule SizeProperty
~120 nodes · 29 capacity rules · 17 variable features · 4 logic gates
L2

Domain Physics

Causal rules

Real-world causal chains: Application → EXPOSES_TO → Stressor → DEMANDS_TRAIT → PhysicalTrait. Environment → REQUIRES_MATERIAL → Material. DependencyRules trigger multi-stage assemblies. This is how the system "knows" hospital = stainless steel without LLM guessing.

Application Environment EnvironmentalStressor PhysicalTrait DependencyRule InstallationConstraint
~80 nodes · 13 stressors · 14 traits · 11 applications · 10 environments

Engine Features

Product Selection

Trait-coverage scoring across product families. Environment, spatial, and capacity constraints applied in sequence.

Constraint Validation

3 types: COMPUTED_FORMULA, SET_MEMBERSHIP, CROSS_NODE_THRESHOLD. Blocked configs get full violation report.

Sales Recovery

When blocked: search same-product alt materials (prong 1) + other families (prong 2). All trait-qualified.

Assembly Detection

DependencyRules trigger multi-stage configs. Params sync across siblings via assembly_group_id.

Smart Clarifications

Graph-driven priority order. Per-tag suppression (not global). 3-layer guard: Engine, Adapter, Retriever.

Full Audit Trail

Every decision traces to graph relationships. Deterministic: same input = same output. No LLM opinion on facts.
